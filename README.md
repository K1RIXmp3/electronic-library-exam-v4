# Электронная библиотека

Экзаменационный проект по дисциплине «Разработка веб-приложений».

**Выполнил:** Осыкин Кирилл
**Группа:** 241-3211
**Вариант:** 4 история посещений и статистика просмотров книг

## Описание

Проект представляет собой небольшую электронную библиотеку на Flask.

В приложении можно:

* просматривать список книг;
* смотреть подробную информацию о книге;
* добавлять, редактировать и удалять книги;
* загружать обложки книг;
* оставлять рецензии;
* просматривать статистику посещений;
* экспортировать статистику в CSV.

Для хранения данных используется SQLite.

## Роли пользователей

В системе есть три роли:

* администратор;
* модератор;
* пользователь.

Администратор может добавлять, редактировать и удалять книги.
Модератор может редактировать книги.
Пользователь может оставлять рецензии.

## Тестовые пользователи

Для проверки можно использовать такие аккаунты:

```text
admin / 123
moderator / 123
user / 123
```

## Запуск проекта

Сначала нужно установить зависимости:

```bash
pip install -r requirements.txt
```

Потом запустить приложение:

```bash
python app.py
```

После запуска сайт будет доступен по адресу:

```text
http://127.0.0.1:5000
```

База данных создаётся автоматически при первом запуске.
Файл базы находится здесь:

```text
data/library.sqlite
```

Обложки книг сохраняются в папку:

```text
data/covers
```

## Вариант 4

В проекте реализована история просмотров книг.

На главной странице есть:

* популярные книги;
* недавно просмотренные книги.

Также для администратора доступна страница «Статистика».
На ней есть две вкладки:

* журнал действий пользователей;
* статистика просмотров книг.

В статистике можно выбрать период по датам и выгрузить данные в CSV.
